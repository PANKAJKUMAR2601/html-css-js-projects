## 📖 Project Overview

Quiz Game is an interactive web application built using HTML, CSS, and JavaScript. It allows users to answer multiple-choice questions, tracks their score in real time, displays progress throughout the quiz, and provides personalized feedback at the end based on performance.

This project demonstrates core frontend development concepts such as DOM manipulation, event handling, dynamic content rendering, state management, and responsive UI design.

---

## ✨ Features

* 🎯 Interactive multiple-choice quiz
* 📊 Real-time score tracking
* 📈 Progress bar for quiz completion
* ✅ Highlights correct answers
* ❌ Shows incorrect selections
* 🔄 Restart quiz functionality
* 📱 Fully responsive design
* 🎉 Dynamic result messages based on score
